# 深いイベント定義 v1 — プロトコル(探索開始前に凍結)

- 凍結日時: 2026-08-16(探索実行前に本ファイルを確定)
- 動機: H5棄却・H6監視リスト入りにより、通年で薄く発生するイベントでは方向の
  エッジがコストを超えないことが確定した。より稀で深いイベント(複数時間軸の
  同時条件、カスケード級の急変動)なら1件あたり期待値がコストを1桁上回る可能性
  を検証する。

## 時間分割(ホールドアウト方式)

| 窓 | 期間 | 用途 |
|---|---|---|
| 探索窓 | データ先頭 〜 2025-06-30 23:55 UTC(実質2023-12-09〜、約19ヶ月) | 候補の探索・ゲート判定 |
| ホールドアウト | 2025-07-01 00:00 UTC 〜 データ末尾(約13.5ヶ月) | 凍結後の追試のみ。探索中は一切クエリしない |

- ホールドアウトには ATH(117k)からの下落・急落月(2025-11, 2026-01/02/06)・
  レンジ月・上昇月(2026-04)が含まれる。
- 注意: 旧 in-sample(2026-07/08)はホールドアウト内にあり、フェード系条件には
  弱い汚染(H6発見の既知情報)がある。結果解釈で明記する。

## 探索のルール

1. 探索エージェントは探索窓のみをクエリする(全SQLに ts < '2025-07-01' を強制)。
2. 条件はイベントバー時点の過去情報のみ(fwd_* を条件に使わない)。
3. 閾値は可能な限りボラ正規化単位(realized_vol_20d 比、drift_20d)で表現する
   (H5の教訓: 絶対bps閾値はレジームを跨いで転移しない)。
4. 効果は**ドリフト調整後**(条件付き平均 − 探索窓の無条件平均)を主指標とする。
5. ホライズンは fwd_return_5m / 1h / 4h のいずれかを宣言する。

## 入場ゲート(凍結対象になる条件。機械的に適用)

- G1: 探索窓で n ≥ 150 かつ 独立エピソード(直前イベントから1時間以上空く)≥ 60
- G2: ドリフト調整後 |効果| ≥ 15bps/件(taker往復10bpsの1.5倍)
- G3: t ≥ 2.0(実効N: 1hは n/12、4hは n/48、5mは n。エピソード数を下回る場合はエピソード数)
- G4: 探索窓を3等分したサブ期間で、効果の符号一致が 2/3 以上
- G5: 凍結は最大5候補(G1-G4通過のうち t 降順)。全候補・全結果を選別なしで報告

## 追試(ホールドアウト)の判定ルール

- 生存: 同符号 かつ |効果| ≥ 探索値の50% かつ ドリフト調整後効果 ≥ taker 10bps
- 生存・コスト未満: 同符号 かつ ≥50% だが < 10bps
- 棄却: 逆符号 または 探索値の25%未満
- N不足: ホールドアウトの独立エピソード < 30 → 恒久ルール1により監視リスト
- 主要値は独立監査エージェントが凍結仕様のみから再計算する
- 事前予想は凍結時に記録し、追試エージェントには見せない

## 結果

### 探索実装の固定解釈

- 実効 N は保守的に `min(n / horizon_bars, 独立エピソード数)` とした。
  (`horizon_bars`: 5m=1、1h=12、4h=48)
- 20日実現ボラで正規化した5m・1h・4hインパルス、単一バー衝撃、ヒゲ拒否、
  直前1h/4hレンジ突破、1時間の同方向バー持続の5族を、継続・フェードおよび
  1h・4hホライズンについて対称に生成した。
- 探索コード: `scripts/deep_events_v1.py`。全952候補の結果は
  `data/analysis/deep_events_v1/exploration_all.csv` に選別なしで保存した
  (953行・239,700 bytes、SHA-256
  `525b37308e202b0347454ea32c312bd029b64542cb8b24de8386e7c5a8b5e3c0`)。
  初回実装はcutoff直前の最大4hで全期間生成済み`fwd_*`を許していたため、target時刻も
  探索窓内にあることを明示するguardを追加して全952件を再計算した。通過数・丸め表示・
  判定は不変だった。

### 探索結果

探索窓169,708本(2023-11-19 17:40〜2025-06-30 23:55 UTC)だけを評価した。

| 単一バー衝撃 | 96 | 96 | +13.05bps | 0.26 |

ノイズと区別できない。

### 判定

**凍結候補0件。深いイベント定義 v1 は探索ゲートで終了。** G1〜G4を通る候補が
無いため、事前予想の記録・ホールドアウト追試は実施しない。2025-07-01以降について、
この952条件の候補別成績は一度も計算していない。期間の大局情報と旧H6に関する弱い
汚染は既知(上記注意)だが、本研究のホールドアウト判定は未消費のまま維持した。
閾値を緩めてニアミスを昇格させることもしない。

主要ニアミス3件(D0801、D0228、D0195)は、候補走査とは別の DuckDB SQL で再計算し、
n・episodes・効果・t が表示桁を超えて一致した。

方向イベントを「より深く・より稀に」すればコスト超えの見かけ上の効果量は作れるが、
証拠量は改善しなかった。次の探索は同じ方向条件の閾値追加ではなく、既に34/34ヶ月で
再現したボラ・流動性構造を目的変数にした予測・サイジング・執行へ移すのが妥当。
