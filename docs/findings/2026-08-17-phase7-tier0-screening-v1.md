### 1.2 有意だが安定性で落ちた 11 test(`conditional_hold_unstable`)

Holm 有意だが §15 の6条件のどれかを満たさない。最も多い脱落理由は

## 2. 方向(Y1)は明確な null

9 test 全てが Holm 非有意。ΔR² は 8/9 で負、唯一の正も +1.02e-05 で MDE を下回る。

| test | ΔR² | MDE | 十分位スプレッド edge | 片道往復コスト |
|---|---:|---:|---:|---:|
| T0-A h=1 / 3 / 12 | −1.24e-04 / −1.67e-04 / −3.39e-04 | −2.8e-05 / −6.9e-05 / −1.2e-04 | +0.37 / +0.48 / +0.72 bps | 10 bps |

| T0-C h=12 / 48 | −1.19e-03 / −4.11e-04 | −1.8e-04 / −3.3e-04 | +3.05 / +8.06 bps | 10 bps |

**edge_bps は上限指標**である(重複保有・執行滑り・建玉制約を無視し、
予測値の上位十分位と下位十分位の実現リターン差を2で割っただけ)。
その上限ですら全 cell で往復コスト 10 bps に届かない。

**この null の正しい読み方**(事前登録 §20):
「Tier 0 の粒度・線形 ridge・この変換の下では、**各 cell の MDE を超える方向情報を
検出できなかった**」であって「方向情報が存在しない」ではない。

## 3. 帰無の作り方が効いていた証拠

**MDE が負の cell が 8 個ある**(うち 7 個は Y1)。例えば T0-B1 h=12 Y3 の MDE は
−6.74e-06 で、placebo 分布の 95 パーセンタイルすら 0 を下回る。これは
「A に X と同じ相関構造を持つ4列を足すと、**普通は out-of-sample が悪化する**」
ことを意味する。罰則が方向(Y1)で特に強いことも読み取れる。

したがって「ΔR² > 0」を有意性の基準にしていたら、**罰則の分だけ楽な検定**になっていた。
A-projection placebo Bp は「この相関構造の列を足したときの帰無分布」を推定するので、
その罰則を正しく織り込む。

- T0-B1 h=12 Y1 は **ΔR² = −1.40e-04(負)なのに第1段階 p = 0.039** だった。
  観測値が placebo 分布の上側にあるからである。第2段階(全数 1,402)で p = 0.039 に確定し、
  Holm 後 0.392 で非有意。**負の効果量は §15 の安定性条件で必ず落ちる**ので昇格には至らない。
- 副次の素朴シフト Bt と主 Bp で、**有意判定が食い違った cell は 0 件**だった。
  Bt は反保守的なので一致は保証されないが、今回は結論を変えなかった。

## 4. 第2段階(全数 placebo)が無ければ全滅していた

18 cell が第2段階へ昇格した(第1段階で `#{placebo >= obs} <= 5`)。

第1段階の K=200 では最小 p が **1/201 = 4.98e-03**。Holm の最小閾値は
**0.05/27 = 1.85e-03** なので、**第1段階だけでは原理的にどの cell も有意になり得ない**。
実際 16 の有意 cell は全て第2段階の p(7.13e-04 / 1.49e-03 / 2.97e-03)で判定されている。

これは事前登録 §12.3 に明記されていた手順であり、緩和ではなく**解像度の調整**である。

## 6. 事前登録との差異の申告

### 6.1 凍結仕様は不変

`tests/test_tier0_prereg.py::test_frozen_spec_was_not_edited_after_the_run` が
artifact に対してこの照合を機械的に行う。

凍結は「仕様」に対して行われたが、実行器 `mce.tier0_screening` には仕様のうち
次が未実装だった。**いずれも効果量を見る前に**補完した。

第2段階の解像度でしか判定できない。

### 6.3 効果量の事前露出(開示)

配管検証のため K=6 に縮めた 2 cell 実行を公式実行の前に行い、その際
**T0-A h=1 Y1 と T0-A h=1 Y2 の観測 ΔR² を見ている**。観測 ΔR² は placebo 数に
依存しないので、実質的に 27 cell 中 2 cell の効果量を先に見たことに相当する。

- その後に凍結パラメータは一切変更していない(6.1 の sha256 照合が証拠)
- smoke artifact は `_smoke` 接尾辞で分離し破棄した
- 最初に起動した実行(第2段階なしの版)は **log 0 バイトで停止**しており、1 cell も
  完了していない。その版から効果量を得てはいない

### 6.4 コンテナ再起動による中断と再開

14/27 cell の時点でコンテナが再起動し実行が落ちた。checkpoint から再開している
(artifact の `resumed_from_checkpoint: true` / `cells_reused_from_checkpoint: 14`)。

再開が「dev の2回目の実行」に当たらない理由: `run_cell` は
`(design, set, horizon, target, stage)` の純関数で他の cell に依存せず、
Holm・BH・安定性・判定は最後に 27 cell 全体へ掛け直す。したがって再開後の artifact は
中断しなかった場合と同一になる。再開前に実行器と凍結仕様が cell 1–14 を出した時点から
不変であることを git で確認した(`c9789e7..HEAD` に `tier0_screening.py` /
`tier0_prereg.py` の変更なし)。

### 6.5 実行時間の実測

事前登録 §18 の見積り「第1段階 ≈ 2.4 時間」に対し、cell 実行時間の合計は **6.03 時間**
(第2段階 18 cell を含む)。4 worker 並列で placebo 1 本あたり実測 1.00 秒。

## 7. この結果が言っていないこと

1. **「Tier 0 に方向情報がある」とは言っていない。** Y1 は 9/9 で非有意、
   コスト換算でも上限指標が往復コストに届かない。
2. **「Y2/Y3 が有意だから儲かる」とは言っていない。** Y2 は実現ボラ、Y3 は下方到達幅で、
   どちらも方向を含まない。ボラ予測から損益を作るには別の実行設計(オプション・
   ポジションサイジング等)が要り、それは本 Phase の範囲外である。
3. **まだ GO は1つも無い。** 5 test は `dev_pass_pending_confirmation` であって GO ではない。
   §17-4(confirmation 窓で符号一致かつ `dR2_conf >= 0.5 * dR2_dev`)は未検証。
4. **統計的非有意 ≠ 同等性。** 非有意だった 11 test は「MDE より大きい効果が無かった」
   であり「効果が 0」ではない。各 cell の MDE を表に併記した。
5. **機序はまだ分かっていない。** 安定性で落ちた 11 test の主因は符号一致であり、
   「どの列がどちら向きに効くか」は fold 間で安定していない。
