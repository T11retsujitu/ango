## 3. 予想が外れたら何を意味するか(先に書く)

| 外れ方 | 解釈 |
|---|---|
| layer 2 で Arm R が **30回以上建った** | ρ の分布が A2 の報告と違う。**ango の `r` 代理(Aave)が A2 と乖離している可能性を最初に疑う**(H12 は代理であって同一ではない) |
| layer 2 で `mean(r_i) > r_f` かつ stress でも正 | **予想外の positive**。ただし7ヶ月・少数 trade なので **layer 3 まで GO を出さない**。§18.3 のとおり |
| replication gate(layer 1)が落ちた | **ango のデータ処理を最初に疑う**。A2 は同一 venue・同一銘柄で成立させている |
| Arm E が always_on へ縮退**しなかった** | §6.2 の恒等式か実装のどちらかが誤り。**T3 が通っているかを確認する** |
